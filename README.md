# wetland_conversion
This project aims to predict which tracts of land in Florida convert from wetland to development, between the years of 2019-2024.

# Directory Structure

- `data/` : TBD
- `scripts/` : TBD
- `wetland_sample_labels.ipynb` : This script creates a label / data set for wetlands that convert to development, remain wetland, or convert to something else. It also generates plots, maps, and displays summary statistics of the NLCD land cover dataset from 2019 - 2024.

See `requirements.yaml` for a recommended conda / mamba installation for this project.
